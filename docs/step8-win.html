# ===== 設定（ここだけ変えればOK）===== NAME = "ジャービス" # 呼びかける名前 CHARA = "ていねいな執事" # 性格・話し方 VOICE = 13 # 声の番号（VOICEVOX） COLOR = "#ff8a24" # 光る色 IDLE = 90 # だまったら終わる秒数
作ったあとでも、名前・性格・声・色はいつでも変えられます。やり方は2つ。

方法A：自分で書きかえる
① VS Codeで、Claudeが「設定はここ」と教えてくれたファイルを開く（上の画面は例です。ファイル名や書き方は人によってちがいます）
② 一番上の「設定」の行の、" " の中や数字だけを書きかえて保存
③ ターミナルで Ctrl + C を押して止め、もう一度 python server.py
④ Chromeの画面を再読み込み（更新ボタン）すると、新しい設定で動きます

書きかえのコツ
・" や = は消さない。消すと動かなくなります
・声は「番号」で書くことが多いです。番号はキャラごとにちがうので、分からなければ方法Bで聞こう
・色は #ff8a24 のような「カラーコード」のことがあります。「緑のカラーコードは？」とClaudeに聞けばOK
・こわいときは、STEP3の「予備（_old）」を作ってから書きかえよう

＋Claude Code で「コピペなし」にする
この講座では「Claudeに頼む → コードをコピー → VS Codeに貼る → 動かす」をくり返しました。Claude Code を使うと、この「コピー・貼る・動かす」を Claude が自分でやってくれます。

たとえば、こんなことができます
・フォルダの中のファイルを読んで、まとめて直してくれる
・エラーが出たら、自分で原因を調べて直してくれる
・「投稿の時間を7時に変えて」と言うだけで、設定ファイルを書きかえてくれる

始め方
① Claude を有料プラン（Pro以上）にする（Claude Code は無料プランでは使えません）
② 公式ページ（code.claude.com）の手順どおりにインストール
③ VS Code の上のメニュー「Terminal」→「New Terminal」 を開き、ai-kouza フォルダで claude と打って Enter
④ いつも claude.ai で使っているアカウントでログイン
⑤ あとは日本語でお願いするだけ。下の文はその例です
