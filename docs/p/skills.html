1🧵 投稿文スキル
テーマを送るだけで、あなたの口調の投稿文を3本。#PRの付け忘れや言い切りもチェック
🔗 使う場所：応用1 Threads・応用2 インスタ
⬇ スキルをダウンロードthreads-post.zip（パソコンで押してね）
claude.ai に入れるClaude Code で使う
  1. 上のボタンでZIPをダウンロード（開かずにそのままでOK）
  2. claude.ai の左下の名前 → カスタマイズ → スキル
  3. ＋ → スキルを作成 → スキルをアップロード
  4. ダウンロードしたZIPを選ぶ → スキルがオンになっていればOK
  1. まず左の「claude.ai に入れる」をやる
  2. Claude Code を開き直すと、自動で入ります（/skills と打つと一覧で見られる）

出てこないときは、下の「スキルの中身」をコピーして、Claude Code に「この内容で ~/.claude/skills/threads-post/SKILL.md を作って」と送ればOK

--- name: threads-post description: ThreadsやインスタのSNS投稿文を頼まれたときに使う。テーマから、その人の口調で投稿文を3本作り、#PR・言い切り・文字数をチェックする。 --- # Threads・インスタの投稿文スキル ## 最初に確かめること - テーマ（何について書くか）。なければ1回だけ聞く。 - 口調の見本：その人の過去の投稿が会話にあれば、それに合わせる。なければ、やさしい話し言葉にする。 - 宣伝（アフィリエイト・自分の商品・頼まれた紹介）を含むかどうか。 ## 作り方 1. 投稿文を **3本** 作る。それぞれ書き出しを変える（問いかけ／体験談／数字）。 2. Threads は1本 **150文字以内**、インスタのキャプションは **300文字以内**。 3. 絵文字は1本に1〜2個まで。改行で読みやすくする。 4. 最後の行にハッシュタグを2〜3個（インスタは5個まで）。 ## かならず守るルール - 宣伝を含むときは、1行目か最後に **#PR** を入れる（ステマ規制）。 - 「必ず稼げる」「絶対やせる」など、結果を言い切らない。 - 人の写真・名前・個人情報は入れない。 - 他人の投稿の文をそのまま使わない。 ## 出し方 1本ずつ「①」「②」「③」の見出しを付けて、そのままコピーできる形で出す。 最後に「どれが好き？直したいところがあれば一言でどうぞ」と1行だけ添える。

--- name: rakuten-room description: 楽天ROOMや楽天アフィリエイトの紹介文を頼まれたときに使う。商品のURLや名前から、#PR付きでステマ規制を守った紹介文を作る。 --- # 楽天ROOM 紹介文スキル ## 最初に確かめること - 商品のURLか商品名。URLが開けないときは、商品名・値段・特徴を貼ってもらう。 - 使った感想があるか（あれば一番大事な材料にする）。 ## 作り方 1. 1行目：**#PR** と、ひとことのキャッチ（20文字くらい）。 2. よいところを **3つ**（・で箇条書き。1つ25文字くらい）。 3. 気になるところ・合わない人を **1つ**（正直に書くと信用される）。 4. 「こんな人におすすめ」を1行。 5. 最後にハッシュタグを3〜5個（#楽天ROOM #楽天購入品 など）。 全部で200文字くらいにする。 ## かならず守るルール - **#PR を必ず入れる**（アフィリエイトは広告。ステマ規制）。 - 使っていないのに「使ってみた」と書かない。感想がないときは「気になっている」「口コミで評判」と書く。 - 「必ず」「絶対」「治る」「やせる」など、効果を言い切らない（健康・美容は特に）。 - 値段やポイント倍率は変わるので「〇月〇日時点」と書くか、書かない。 ## 出し方 コピーしやすいように紹介文だけを出し、最後に「別の書き出しも作る？」と1行添える。

--- name: subtitle-srt description: 動画の字幕やSRTファイルを頼まれたときに使う。話した内容（文字起こし）から、スマホで読みやすいSRT字幕を作り、subtitle.srtとして渡す。 --- # 動画の字幕（SRT）スキル ## 最初に確かめること - 文字起こしの文。時間（タイムコード）付きならそれを使う。 - 時間がないときは、動画の長さ（秒）を聞く。わからなければ、1秒に6文字くらいの速さで時間を割りふる。 ## 作り方 1. 1つの字幕は **1行16文字まで・2行まで**。句読点や意味の切れ目で区切る。 2. 1つの字幕は **1〜4秒** 表示する。前の字幕と時間が重ならないようにする。 3. 「えー」「あのー」などの言いよどみは消す。言いまちがいは直す（意味は変えない）。 4. 数字は読みやすく（3まん → 3万）。 ## SRTの形 ``` 1 00:00:00,000 --> 00:00:02,400 ここに字幕の文 2 00:00:02,400 --> 00:00:05,000 次の字幕の文 ``` ## 出し方 - ファイルが作れるときは **subtitle.srt**（文字コードはUTF-8）として保存して渡す。 - 作れないときは、上の形のまま全部をコードブロックで出す。 - 最後に「CapCut には字幕ファイルの読み込みで入れられます」と1行添える。

--- name: line-stamp description: LINEスタンプを作りたいと頼まれたときに使う。キャラ・使う人・雰囲気から、セリフと絵の指示をまとめ、LINEのサイズのルールに合わせて準備する。 --- # LINEスタンプ スキル ## 最初に確かめること（なければ1回でまとめて聞く） - どんなキャラ？（例：まるいクマ、ねこ、自分の似顔絵の動物） - だれが使う？（例：家族、友だち、仕事仲間） - 雰囲気（例：ゆるい、元気、ていねい） - 何個のセット？（8・16・24・32・40個。初めてなら8個がおすすめ） ## 作り方 1. 使う場面を考えて、セリフを個数ぶん作る（あいさつ・お礼・返事・気持ち・あいづち をまんべんなく）。 2. 1個ずつ「セリフ／表情／ポーズ」を表にする。 3. 画像が作れるときは、同じキャラで表情を変えて作る。 - スタンプ：よこ370×たて320 以内・偶数の大きさ・背景は透明PNG・まわりに10pxの余白・1枚1MB以下 - メイン画像：240×240、タブ画像：96×74 4. タイトル（40文字以内）と説明文（160文字以内）を日本語と英語で作る。 ## かならず守るルール - **オリジナルのキャラだけ**。アニメ・ゲーム・有名キャラ、芸能人、実在の人に似せない。 - 写真そのものは使わない。 - 文字は太く、スマホで小さく見ても読めるようにする。 ## 出し方 まずセリフの表を見せて「これでよければ絵を作ります」と聞く。OKが出たら画像づくりに進む。

--- name: selfback-navi description: A8.netのセルフバック案件を探したい・おすすめを聞かれたときに使う。条件（無料・スマホ・金額など）に合う案件を、A8で検索できるIDつきで5つ選ぶ。 --- # セルフバック相談スキル ## 案件リスト 講座のセルフバック案件リスト（毎朝更新）を読む： https://akoolsnsproject-beep.github.io/nexora-kouza/selfback.json - items の各案件に name（名前）・reward（報酬）・condition（条件）・category・free（無料でできる）・easy（スマホで10分くらい）・id（A8のプログラムID）がある。 - 開けないときは、ユーザーに「LINEのリッチメニュー［💰セルフバック］を開いて、気になる案件の名前を貼ってね」とお願いする。 ## 選び方 1. ユーザーの条件を読む（例：無料で、スマホで、1万円以上、カード以外）。条件がなければ「無料」「かんたん」を優先する。 2. 条件に合う案件を報酬の高い順に **5つ** 選ぶ。 3. 同じ種類（カードばかり など）が続かないようにする。 ## 出し方 1件ずつ： - **名前**　報酬 - 条件（1行） - A8で検索：id（idがなければ名前） - 注意（お金がかかる・審査がある・解約が必要 などがあれば1行） 最後に「A8.netのセルフバックで検索欄にIDを貼ると見つかります。本人確認はスマホが楽です」と添える。 ## かならず守るルール - 「必ずもらえる」と言い切らない。報酬は変わることがあると伝える。 - 借入・ギャンブルっぽい案件はすすめない。 - 申し込みに必要な個人情報やパスワードは聞かない・預からない。
