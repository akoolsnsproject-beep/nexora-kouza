直してもらう前に、ファイルの予備（コピー）を作っておきます。
① Finderで ai-kouza を開き、rename.py を右クリック →「複製」
②「rename のコピー.py」ができるので、右クリック →「名前を変更」
③ 名前を rename_old.py にして return
まちがえて書きかえても、rename_old.py の中身を使えば元どおり。VS Codeで打ちまちがえたときは command + Z で1つ前に戻せます。
直すときは、元のファイルは消さずに、新しい名前（rename_v2.py）で作ってください。
